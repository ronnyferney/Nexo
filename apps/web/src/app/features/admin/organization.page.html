Cómo funciona

  • Cada miembro pertenece a una unidad; por defecto, la raíz.
  • El chat de un usuario se cobra a su unidad; las ejecuciones sin usuario (flujos, webhooks, MCP) al centro de costo del agente o, si no tiene, a la raíz.
